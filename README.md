# LPSN_API

Repository providing an example on how to use the LPSN R package to make API calls to the "List of Prokaryotic Names with Standing in Nomenclature" database to correct taxonomic lineage issues arising from the various synonyms or name modification applied by different taxonomy databases.

It contains an example workflow and requires data cleaning before making the API call.

This is not regularly maintained but may change periodically.

Use at your discretion.
